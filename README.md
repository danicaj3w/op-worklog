# OP Worklog
An app geared towards staying consistent with learning any skill you want. 

# Background
I'm a lifelong learner! I have many creative outlets;  digital illustration, animation, 3D modeling, you name it. Other times, I'll be dabbling in graphic design or web design for games. 

However, this means I have a lot of things to learn and never enough time. As a solution, I'm aiming to pack my most helpful methods into an app. OP Worklog is a play on one of my original inspirations, WLOP, or Wang Ling
